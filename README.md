# Dr.Fishco Solutions website

Static site for **drfishcosolutions.com**, served by GitHub Pages from the `main` branch root.

- `index.html`, `products.html`, `about.html`, `contact.html`: pages
- `assets/css/style.css`: all styles (brand navy `#003471`, green `#459522`)
- `assets/js/main.js`: menu, scroll reveals, tabs, gallery, WhatsApp enquiry form
- `assets/img`, `assets/logo`, `assets/fonts`: images, logos, self-hosted Poppins
- `CNAME`: custom domain for GitHub Pages
